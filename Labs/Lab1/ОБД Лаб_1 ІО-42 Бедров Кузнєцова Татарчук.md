##### **Вимоги:**

База даних має містити інформацію про студію розробки програмного забезпечення, достатню для оцінки і менеджменту батьківською структурою або корпорацією. А саме:  
  
- Показники успішності опублікованої версії;  
- Інформація про усіх працівників, їх статус та посади;  
- Прогрес розробки та внутрішню структуру проекту;

##### **Опис зв'язків:**
  
Worker - Contract  
Один працівник може укласти один або багато контрактів.  
  
Worker - Wing  
Керівник: Працівник може бути керівником довільної кількості відділів.  
Працює: Один або кілька працівників можуть працювати у довільній кількості відділів.  
  
Job - Contract  
Кожні посада може мати кілька працевлаштованих або не мати жодного.  
  
Job - Wing  
Обіймана посада у відділі: Кожен відділ має одну або багато посад.  
  
Wing - Project  
Робота: Різні відділи можуть працювати над різними проектами.  
  
Wing - Beta_Branch  
Внесення змін: Над однією бета версією працює один або більше підрозділів.  
  
Beta_Branch - Release  
Версія релізу: Один реліз може мати одну або кілька бета версій.  
  
Release - User  
Зовнішні тестувальники: Один реліз може мати будь-яку кількість користувачів.  
  
User - Review  
Серія відгуків користувачів: Один користувач може залишити багато відгуків або не залишити жодного.  
  
Project - Release  
Історія версій: Єдиний проект має кілька релізів або не має жодного.
